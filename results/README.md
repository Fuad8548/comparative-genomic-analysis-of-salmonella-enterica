# Results Index

This directory organizes the outputs of the comparative-genomics workflow.

## Subdirectories

- `pangenome/` — Roary gene-cluster tables, presence/absence data, and pangenome summaries.
- `amr/` — AMRFinderPlus hit-level records and derived AMR presence/absence tables.
- `vfdb/` — ABRicate/VFDB reports, marker-frequency summaries, and presence/absence matrices.
- `figures/` — Final figures generated from the checked result tables, where available.

## Data Traceability

Distinguish original tool outputs from derived summaries. For any derived table or figure, record the source file and the transformation or filtering rules used.

Only refer to files that actually exist and have been checked. Do not treat placeholder filenames as completed outputs.
